    I like building things, mostly to find out how stuff works. The island above is one of them: every building on it is a project. Here is the same list without the walking.

    Things I've built

    • IP Map

      the lighthouse

      Who owns this IP address? Every published IP range of the world's biggest cloud on one searchable map. Paste an address to see its region and service, browse its history back to 2015, or build an allowlist. It re-syncs itself every 30 minutes.

      Open IP Map · Source

    • Scaling Visualiser

      the windmill

      An interactive, browser-only simulation of how serverless functions scale when traffic hits: concurrency, cold starts, warm reuse, scaling rate and throttling.

      Open the visualiser · Source

    • URL X-Ray

      the x-ray lab

      An evidence-first, interactive map of the public internet infrastructure behind a URL: live DNS records, the networks and organisations behind each address, and reverse DNS.

      Open URL X-Ray · Source

    • This island

      you are standing on it

      A living ASCII world grown from one number with fractal noise, roads carved by A*, a day and night cycle, and a lighthouse that actually sweeps. Plain JavaScript and one canvas, no frameworks.
